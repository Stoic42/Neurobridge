### 数据流架构

```
┌─────────────┐
│   User A    │
│  (ASD)      │
└──────┬──────┘
       │
       │ 1. 输入文本
       │    "我不是否定你的情绪..."
       │
       ▼
┌─────────────────┐
│  LeftPanel      │
│  - Text Input   │
│  - Send Button  │
└──────┬──────────┘
       │
       │ 2. WebSocket.send()
       │    {type: "text_message", text: "...", ...}
       │
       ▼
┌─────────────────────────────────┐
│  WebSocket Client               │
│  (React Hook / Service)         │
└──────┬──────────────────────────┘
       │
       │ 3. WS Protocol
       │
       ▼
┌─────────────────────────────────┐
│  Backend WebSocket Endpoint      │
│  /ws/{room_id}/{user_id}         │
└──────┬──────────────────────────┘
       │
       ├─────────────────┐
       │                 │
       ▼                 ▼
┌──────────────┐  ┌──────────────┐
│ Broadcast to │  │  AI Analysis│
│  User B      │  │  (Async)    │
└──────┬───────┘  └──────┬───────┘
       │                 │
       │                 │ 4. LLM Service
       │                 │    translate()
       │                 │
       │                 ▼
       │          ┌──────────────┐

       │          └──────┬───────┘

       │                 │    analysis_result
       │                 │
```

## 🔄 交互流程

### 场景 1: 用户发送消息

```
User A 输入文本
    ↓
点击 [Send] 按钮
    ↓
显示 "Sending..." 状态
    ↓
WebSocket 发送消息
    ↓
消息出现在 LeftPanel
    ↓
(异步) AI 分析开始
    ↓
AICenter 显示 "Analyzing..."
    ↓
分析结果返回
    ↓
AICenter 更新显示:
    - Intent
    - Misread
    - Rewrite Suggestions
    - Emotion Intensity
    ↓
RightPanel 显示收到的消息
```

### 场景 2: 用户选择改写建议

```
用户查看 Rewrite Suggestions
    ↓
点击 [Empathetic] 按钮
    ↓
显示改写后的文本
    ↓
提供 [Copy] 和 [Use This] 按钮
    ↓
点击 [Use This]
    ↓
文本自动填入输入框
    ↓
用户可以再次编辑或直接发送
```

### 场景 3: 查看历史分析

```
点击 HistoryTimeline 中的消息
    ↓
显示该消息的完整分析结果
    ↓
可以展开/折叠详细信息
    ↓
提供 [Copy Analysis] 功能
```
