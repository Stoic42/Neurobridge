# 黑客松优先级规划

## 时间约束分析

**可用开发时间**: 6小时 (12:00-19:00)
**Demo时间**: 3分钟展示 + 1分钟Q&A
**主题要求**: AI-Native产品，鼓励使用文心4.5系列模型

## MVP功能优先级 (6小时内必须完成)

### P0 - 核心功能 (前3小时)
1. **基础翻译功能** - 最高优先级
   - 角色选择 (ASD/NT/不确定)
   - 文本输入框
   - 调用文心4.5 API进行意图解析
   - 显示翻译结果 (意图/误解/改写)

2. **简单UI界面**
   - 参考轻闪MBTI的卡片式设计
   - 基础的响应式布局
   - 清晰的信息层次

### P1 - 增强体验 (第4-5小时)
3. **情绪温度计**
   - 简单的0-100数值显示
   - 基础的可视化组件

4. **语气调整**
   - 三个快捷按钮 (直接/温和/共情)
   - 一键重新生成表达

5. **错误处理**
   - 基础的加载状态
   - 简单的错误提示

### P2 - Demo加分项 (第6小时)
6. **本地历史记录**
   - localStorage存储最近5条记录
   - 简单的历史查看

7. **Demo演示数据**
   - 准备5-8个典型的沟通场景
   - 预设的示例对话

## 技术栈决策

### 前端 (推荐)
- **Vite + React + Tailwind CSS**
  - 快速启动和热重载
  - 组件化开发效率高
  - 样式快速迭代

### 后端 (推荐)
- **FastAPI + Python**
  - 快速API开发
  - 自动生成API文档
  - 易于集成多种LLM API

### LLM集成 (按优先级)
1. **文心4.5** - 主要模型 (符合黑客松推荐)
2. **GPT-4o** - 备用选项
3. **本地模型** - 离线演示备份

## Demo脚本规划

### 开场 (30秒)
"神经多样性人群在沟通中经常遇到误解。我们的NeuroBridge不是要'修复'任何人，而是要搭建理解的桥梁。"

### 核心演示 (90秒)
1. **场景1**: ASD用户说"我不知道为什么你要生气，这不合逻辑"
   - 展示系统如何解析真实意图
   - 显示NT用户可能的误解
   - 生成更合适的表达方式

2. **场景2**: NT用户的含蓄表达
   - 展示反向翻译功能
   - 突出AI-Native的实时理解能力

### 技术亮点 (30秒)
- 多模型支持和自动切换
- 情绪温度计的可视化
- 一键语气调整功能

### 结尾 (30秒)
"我们相信技术应该增进人与人之间的理解，而不是替代真实的情感连接。"

## 风险缓解

### 技术风险
- **API限制**: 准备多个API key和备用模型
- **网络问题**: 准备离线演示数据
- **时间不足**: 优先完成P0功能，其他功能可以用静态展示

### 演示风险
- **准备多个演示场景**: 避免单一场景失败
- **备用演示方案**: 准备录屏视频作为备份
- **简化复杂功能**: 专注于核心价值展示
